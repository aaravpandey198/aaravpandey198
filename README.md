## 02. About Me

I'm **Aarav Pandey**, a second-year B.Tech Computer Science & Technology student at JIS College of Engineering, focused on building strong software engineering fundamentals and developing into an **AI Engineer**.

I approach engineering as more than writing code. I care about understanding the problem, designing maintainable solutions, choosing appropriate data structures, structuring APIs, and building software that solves practical user problems.

My technical journey combines data science, Python development, applied machine learning, and product-oriented engineering. I enjoy working with data, experimenting with AI-powered workflows, and translating ideas into functional project prototypes.

- **Software Engineering:** Python programming, algorithmic problem-solving, modular application design, debugging, and version control.
- **AI / Machine Learning:** Data preparation, exploratory data analysis, machine learning fundamentals, and the mathematical foundations behind intelligent systems.
- **Full-Stack Development:** Exploring the complete application lifecycle, from user-facing interfaces to backend APIs, databases, and AI integrations.
- **Product Engineering:** Building around real problems, practical requirements, reliability, usability, and measurable value.
- **Continuous Improvement:** Strengthening DSA, learning ML systematically, and documenting my work through GitHub repositories.
